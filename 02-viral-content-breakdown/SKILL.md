# viral-content-breakdown

用于对标内容和爆款作品拆解。核心功能是把外部内容拆成可学习的机制、可迁移的结构和可执行的下一步建议。

本 Skill 只做拆解、判断和迁移建议，不直接抄写原文、不自动生成选题池、不自动写大纲、不自动改稿。

## 触发条件

使用这个 Skill 处理：

- 用户说“帮我拆一下这个爆款”“这个内容为什么火”“拆解这个对标作品”
- 用户提供对标账号、爆款文章、短视频文案、截图、链接、标题、封面或评论区反馈
- 用户想从爆款内容中提炼标题结构、开头钩子、内容结构、故事模板、语言风格或视觉节奏
- 用户想判断某个爆款方法能不能迁移到 Emma 的账号、业务模块或平台
- 用户想获得一组用于继续拆解同类内容的提示词

不要用这个 Skill：

- 用户还没有对标内容，只是在找选题 -> 生成选题（`topic-generator`）
- 用户已经确定一个题目，需要整理大纲 -> 内容大纲（`content-outline-builder`）
- 用户需要把已有稿件润色、去 AI 味或改标题 -> 大纲扩写（`outline-expander`）
- 用户需要发布前合规检查 -> 内容审稿（`adversarial-content-review`）
- 用户提供的是自己已发布内容的数据后台 -> 数据复盘（`data-analysis`）

## 分析维度

### 1. 选题入口

判断它击中了什么入口：

| 入口 | 判断问题 |
| --- | --- |
| 痛点 | 用户是不是一眼知道“这和我有关” |
| 情绪 | 是否抓住焦虑、委屈、好奇、认同、爽感、反差或共鸣 |
| 收益 | 用户看完能得到什么具体好处 |
| 热点 | 是否借用了平台正在讨论的话题 |
| 身份 | 是否让某类人产生“说的是我”的代入感 |

### 2. 标题、封面和开头

重点判断用户为什么点进来、为什么停下来看：

- 有没有把痛点、冲突、反差、悬念、数字或具体收益前置。
- 有没有废话开头；短视频尤其检查前 3 秒是否直接给爆点。
- 封面文字是否足够具体，是否能和标题互补。

### 3. 内容结构

拆出内容展开顺序，不强行套模板。常见有效结构：

- `问题 -> 解法 -> 案例 -> 行动`
- `冲突 -> 解释 -> 反转 -> 方法 -> 金句`
- `痛点 -> 错误做法 -> 正确做法 -> 结果对比`
- `故事开场 -> 困境 -> 转折 -> 经验 -> 互动引导`

### 4. 故事和案例

检查是否有：

- 人物：用户能代入谁。
- 冲突：遇到什么困难、误区或矛盾。
- 转折：发生了什么变化。
- 细节：是否有时间、动作、场景、数字或具体物件。

如果没有完整故事，判断是否使用了“伪故事结构”：`问题 + 动作 + 结果`。

### 5. 语言风格

判断它是否像人在说话：

- 是否口语、短句、好懂。
- 是否有比喻、情绪、细节、金句。
- 是否有共鸣钉子，例如让用户觉得“这就是我”。
- 是否过度夸张、强刺激或不适合 Emma 的表达边界。

### 6. 视觉、节奏和互动

图文重点看：封面、排版、截图、表格、配图、段落长度。

视频重点看：前 3 秒、字幕、特写、BGM、音效、转场、语速、画面节奏。

互动重点看：评论引导、收藏理由、转发理由、评论区高赞句和私信线索。

### 7. 可迁移性

把拆解结果分成三类：

| 类型 | 含义 |
| --- | --- |
| 可直接迁移 | 结构、分析维度、提问方式、节奏方法 |
| 需要改写迁移 | 标题句式、情绪表达、故事类型、视觉形式 |
| 不建议迁移 | 原句照搬、身份不符、事实不可验证、风险表达、过度制造焦虑 |

## 输出格式

### 爆款拆解结论

先用一句话说明：这条内容主要火在什么机制上。

### 爆款机制拆解

| 维度 | 具体表现 | 为什么有效 | 可迁移性 |
| --- | --- | --- | --- |
| 选题入口 | string | string | 可直接迁移 / 需要改写 / 不建议 |
| 标题/封面/开头 | string | string | string |
| 内容结构 | string | string | string |
| 故事/案例 | string | string | string |
| 语言风格 | string | string | string |
| 视觉/节奏 | string | string | string |
| 互动设计 | string | string | string |

### 可复制的内容骨架

用 1 套通用公式表达，不要照搬原文：

```text
[用户痛点] -> [冲突/反差] -> [具体案例] -> [方法/判断] -> [行动或互动引导]
```

### 不建议复制的部分

列出 3-5 条不建议直接学习的地方，例如：

- 原句、标题或故事细节过于相似，容易变成抄袭。
- 事实、数据、身份或经历无法验证。
- 医美内容存在疗效承诺、外貌焦虑、强对比刺激或绝对化表达。
- 不符合 Emma 的账号模式、专业边界或长期人设。

### 迁移到 Emma 账号的方式

只给 1-3 个可迁移方向，每个方向必须说明：

| 方向 | 怎么迁移 | 适合平台 | 风险提醒 |
| --- | --- | --- | --- |
| string | string | string | string |

### 可直接复用的提示词

至少给 3 类，按本次拆解目标选择：

- 爆款总拆解提示词
- 标题/开头拆解提示词
- 结构复用提示词
- 风格改写提示词
- 视觉和剪辑拆解提示词
- 评论区反馈提炼提示词

### 下一步建议

根据拆解结果只推荐一个下一步：

- 想把可迁移方向变成候选题：生成选题（`topic-generator`）
- 已确定一个迁移方向，需要搭结构：内容大纲（`content-outline-builder`）
- 已有自己的稿件，需要改得更像人说话：大纲扩写（`outline-expander`）
- 拆解对象存在医美、营销或风险表达，准备借鉴前先审查：内容审稿（`adversarial-content-review`）
- 信息不足：补对标内容/补平台数据/补评论反馈

## Guardrails

- 不把“爆款”包装成可保证复制的结果。
- 不直接复写对标内容的原句、标题、故事细节或独特表达。
- 不虚构播放、点赞、评论、转发或平台推荐机制。
- 没有数据时，只判断内容策略，不判断真实表现。
- 对标账号只作为结构和方法参考，不复制其身份、经历、口吻或事实。
- 医美内容不得迁移外貌焦虑、疗效承诺、强对比刺激、绝对化结果或诱导性营销表达。
- 输出只做拆解和迁移建议；除非用户明确要求进入下一阶段，否则不自动生成选题、大纲、正文或发布包。
