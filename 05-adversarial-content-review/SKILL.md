# 内容审稿

这是 Emma 内容系统唯一的发布前审稿 Skill。它合并原「内容审稿」和「合规检查」能力，负责同时判断内容质量、账号匹配、读者体验、专业可信度、合规风险和转化风险。

## 触发条件

- 用户说“内容审稿”“审稿”“帮我检查一下”“这篇能发吗”
- 用户说“做合规检查”“检查风险表达”“发布前复核”
- 用户要求从 Emma 人设、目标用户、专业可信度、阅读体验、转化风险等角度审稿
- 稿件涉及医美项目、效果、适应人群、恢复期、案例对比、资质、诊疗建议或平台发布风险
- `outline-expander`、`voice-script-writer` 产出成稿后需要进入发布前检查

**不触发：**

- “写文章” → 大纲扩写（`outline-expander`）
- “改标题”“去AI味”“润色” → 大纲扩写（`outline-expander`）
- “整理大纲” → 内容大纲（`content-outline-builder`）
- “复盘数据” → 数据复盘（`data-analysis`）

## 不做什么

- 不另行生成审稿报告文件。
- 不只给问题清单后停下；发现问题时直接修改到原文。
- 不做选题，不做内容大纲，不做发布。
- 不替代律师、平台审核、医疗合规人员或医生面诊判断。
- 不把非认证人格号稿件改成医生诊疗表达。

## 执行前读取

必须读取：

- `../_shared/knowledge-base-index.md`
- `../_shared/account-mode-guide.md`
- `../_shared/channel-safety-guide.md`
- `../_shared/style-guide.md`
- `../_shared/intermediate-format.md`
- `references/review-rubric.md`

如果 Emma 尚未提供具体合规原文或最新平台规则，按更保守的风险清单审查，并在修订说明里提示发布前仍需人工复核。

## Step 1：确认待审稿件

读取用户指定的文章、口播稿、发布包或前文成稿，提取：

- 标题/封面标题/字幕/正文/口播稿/CTA
- 稿件类型：文章、口播、图文、发布包、评论区引导
- 账号模式：认证医生号 / 非认证人格号 / 待确认
- 发布平台：公众号 / 视频号 / 小红书 / 多平台 / 待确认
- 目标用户
- 来源大纲或素材依据

如果没有成稿，只提示用户补充待审稿内容，不生成空文件。缺失项按表格列出：稿件正文、账号模式、发布平台、目标用户、风险边界。

## Step 2：判断审稿级别

| 审稿级别 | 触发条件 | 必做检查 |
| --- | --- | --- |
| 常规审稿 | 创业、女性状态、AI、生活观察、普通内容 | 人设、目标用户、可信度、阅读体验、转化风险 |
| 医美审稿 | 涉及项目、效果、恢复期、适应人群、案例、诊疗建议 | 常规审稿 + 医美风险逐句扫描 + 替代表达 |
| 发布包审稿 | 包含标题、封面、字幕、正文、标签、CTA、评论引导 | 常规审稿 + 全部发布元素逐项检查 |

不确定账号模式时，按更保守口径处理，并在修订说明中标注“账号模式待确认”。

## Step 3：三角色对抗审稿

### 角色 1：笔杆子

以内容专家视角检查：

- 核心观点是否一句话说清
- 结构是否顺，章节/段落是否各自交付价值
- 论据、案例、用户素材是否支撑观点
- 有没有空泛升华、逻辑跳跃或自相矛盾

### 角色 2：参谋

以目标读者视角检查：

- 开头 3 秒/前 3 句能不能抓住人
- 哪里看不懂、想跳过、觉得被说教
- 哪里有共鸣、想收藏、想转发
- 读完是否知道自己能带走什么

### 角色 3：风控官

以账号边界和平台风险视角检查：

- Emma 人设是否跑偏
- 是否制造容貌焦虑、女性焦虑或 AI/创业焦虑
- 是否强导流、强成交、强营销
- 是否出现医美疗效承诺、绝对化表达、诊疗建议或资质暗示
- 标题、封面文字、屏幕字幕、正文、评论引导和 CTA 是否都安全

## Step 4：合规风险清单

逐句扫描以下风险。发现问题时必须定位原句/位置，直接替换为更稳妥表达，并保留内部判断依据用于最终修订说明。

| 风险类型 | 高风险表现 | 更稳妥方向 |
| --- | --- | --- |
| 疗效承诺 | 保证变美、一定改善、永久有效、立刻见效、一次解决、无恢复期 | 可能改善的方向、需要结合基础条件判断、结果存在个体差异 |
| 绝对化表达 | 最安全、唯一、首选、100%、人人适合、没有副作用、无风险 | 需要了解风险、禁忌、恢复安排，并由医生判断 |
| 焦虑营销 | 不做就老、脸垮、毁脸、输在起跑线、必须马上处理 | 很多人会在意这种变化，可以先了解原因和判断路径 |
| 前后对比 | 暗示固定效果、夸张对比、未说明个体差异 | 案例只作为个体情况，不代表普遍结果 |
| 资质暗示 | 暗示非医生可诊断/治疗，夸大机构或专家背书 | 明确回到专业评估和合规资质边界 |
| 诊疗建议 | 未面诊给项目方案、剂量、治疗结论 | 类似表现可能有不同原因，具体情况需要专业评估 |
| 风险提示缺失 | 只讲好处，不讲禁忌、恢复、个体差异和面诊必要性 | 增加判断条件、风险提醒和面诊问题 |
| 平台表达风险 | 价格诱导、强 CTA、案例真实性不清、过度功效词 | 以认知分享、判断清单和温和互动替代 |
| 非认证人格号越界 | 以医生身份给方案、推荐项目、判断适应人群 | 分享一般观察，医疗问题回到专业评估 |
| AI/创业焦虑 | 不会 AI 就被淘汰、靠 AI 轻松赚钱、抓住风口暴富 | 讲真实变化、工作体验和长期判断，不许诺收益 |

## Step 5：裁判裁定

综合三角色意见，给出五角度评分和最终结论。

| 维度 | 满分 | 判断重点 |
| --- | ---: | --- |
| Emma 人设 | 2 | 是否符合账号模式、语气、身份边界和 Emma 的长期主义气质 |
| 目标用户 | 2 | 是否具体命中目标读者的真实问题，而不是泛泛表达 |
| 专业可信度 | 2 | 是否有素材、判断链、案例或风险提醒支撑；医美内容是否守住专业边界 |
| 阅读/观看体验 | 2 | 标题/开头/节奏/结构/字幕是否顺，是否有 AI 稿痕迹 |
| 转化与合规风险 | 2 | 是否低风险、低营销感、CTA 克制，是否需要替代表达 |

| 总分 | 结论 | 处理 |
| ---: | --- | --- |
| 8-10 | 通过 | 可进入人工发布确认；如有轻微问题直接修订 |
| 5-7 | 需修改 | 按 P0/P1/P2 定位问题并直接修订原文 |
| <5 | 需重写 | 说明是方向错误、素材不足、表达失败还是高风险导致 |
| 任意分数但出现高风险医美表达 | 高风险需重写/重审 | 不得直接建议发布 |

## Step 6：直接修订原文

读取 `../_shared/intermediate-format.md` 中“内容审稿修订”的格式规范。默认不创建 `review-report.md`，也不输出完整审稿报告。

处理方式：

- 用户提供本地 Markdown 文件路径时，直接修改该原文件。
- 用户提供的是聊天中的成稿文本时，在聊天中输出“修订后全文”，不另存审稿报告。
- 用户明确要求保留原稿时，才另存为 `<原文件名>-审稿修订.md`；否则默认覆盖原中文标题 Markdown 文档。
- 高风险且无法在不改变核心事实的情况下修稳时，不强行改写；只说明“高风险需重审”和需要用户补充/确认的问题。

聊天回复只给简短修订说明：

- 审稿对象
- 处理结果：已通过 / 已直接修订 / 高风险需重审
- 主要修改点：3-5 条，按 P0/P1/P2 标注
- 已修改文件链接或修订后全文
- 剩余需要 Emma 人工确认的问题
- 下一步建议：人工发布确认 / 数据复盘（data-analysis）/ 返回内容大纲（content-outline-builder）

## 优先级规则

| 优先级 | 定义 |
| --- | --- |
| P0 | 不改不建议发布：高风险表达、账号跑偏、核心观点不成立、明显误导 |
| P1 | 建议发布前修改：人设弱、论据不足、开头不抓人、结构跳跃、抽象空泛 |
| P2 | 可选优化：标题更好、CTA 更自然、字幕更短、语气更像 Emma |

## Guardrails

- 不能跳过风控官审稿；合规检查已经并入本 Skill。
- 不再建议调用独立合规检查 Skill。
- 五角度评分用于内部判断；最终只在必要时简要说明，不输出完整评分报告。
- 修改必须具体落到原文位置；不能只说“需要优化”。
- 只要出现明确疗效承诺、未面诊诊疗结论、严重焦虑营销或非认证人格号医疗越界，结论至少为“需修改”；无法保留原意时判为“高风险需重审”。
- 审稿默认直接修改原稿；除非用户明确要求“只审不改”。
