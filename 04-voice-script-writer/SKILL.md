# voice-script-writer

用于把已确认的文章、大纲或素材转成可录制的短视频口播稿和轻量分镜。它合并大纲直出口播和文章改口播能力，是口播脚本的唯一入口。

执行前读取 `../_shared/knowledge-base-index.md`、`../_shared/account-mode-guide.md`、`../_shared/channel-safety-guide.md`、`../_shared/style-guide.md`、`../_shared/intermediate-format.md` 和 `references/voice-script-structure.md`，保证口播稿延续 Emma 的账号身份、专业边界和内容交接格式。

## 触发条件

- 用户说“根据这个大纲生成口播稿”“写口播稿”“做短视频版本”
- 用户输入 `/口播`
- 用户说“改成口播稿”“改口播”“改成视频文案”
- 已有 `content-outline`、文章草稿、选题结构、访谈素材，想直接生成 60/90/180 秒版本
- 需要封面标题、封面提示词、视频标题、标签、评论区引导、分镜建议或小白能听懂的医美口播

**不触发：**

- “写文章” -> 大纲扩写（`outline-expander`）
- “改标题”“去 AI 味”“润色” -> 大纲扩写（`outline-expander`）
- “审稿”“发布前检查” -> 内容审稿（`adversarial-content-review`）
- 只有模糊方向且没有核心素材 -> 生成选题（`topic-generator`）

## 输入判断

| 输入类型 | 处理方式 | 默认输出目录 |
| --- | --- | --- |
| 完整文章 / `article-draft.md` | 提取 1 个核心观点、1-2 个最强论据或案例，改成口播 | `content-production/文章改口播/` |
| 内容大纲 / `content-outline.md` | 按大纲主线直接生成口播、分镜、封面标题和发布素材 | `content-production/口播脚本/` |
| 访谈素材 / 选题结构 | 先整理目标受众、核心观点、可用素材和风险边界，再生成口播 | `content-production/口播脚本/` |

如果没有大纲、文章或核心素材，先向用户要：主题、目标受众、核心观点、必须保留的信息和禁讲边界。

## 生成原则

- 默认优先输出 90 秒版本；用户指定时长时按用户要求。
- 口播只讲一件事，一句话一个重点，短句为主，减少书面语。
- 开头 3-5 秒必须给观看理由，但医美内容不能靠制造容貌焦虑吸引注意。
- 保留专业判断链：问题是什么、为什么会发生、怎么判断、什么时候需要面诊。
- 从文章改口播时保留原文核心观点，不自由发挥。
- 从大纲或素材直出口播时，只使用用户提供或可明确推断的素材；没有案例就写成“常见情况/沟通场景”。
- 允许有情绪和共鸣，但不能夸大痛点、承诺效果或暗示“不做就会变差”。

## 账号模式结构

| 账号模式 | 主结构 | 特别限制 |
| --- | --- | --- |
| 认证医生号 | 问题 -> 原因 -> 判断条件 -> 风险与面诊提醒 | 可以表达医生判断，不在线诊断或推荐固定方案。 |
| 非认证人格号 | 观察 -> 共鸣 -> 认知 -> 留白 | 以创业、生活或女性状态观察为主，不使用诊疗语气。 |

账号模式为待确认时，先向 Emma 确认；无法确认而必须出草稿时，按非认证人格号的保守边界输出并显式标注。

## 可选结构

根据素材选择一种，不要机械套用：

| 结构 | 适合场景 |
| --- | --- |
| 痛点误区 -> 原因 -> 判断方法 -> 提醒 | 用户有明确困扰或常见误解 |
| 结果前置 -> 条件拆解 -> 风险提醒 -> 行动建议 | 用户想知道某项目是否适合 |
| 反常识观点 -> 解释 -> 案例/场景 -> 总结 | 需要做专业认知纠偏 |
| 问题清单 -> 分层回答 -> 决策建议 | 适合小白科普和收藏型内容 |
| 钩子 -> 冲突 -> 观点 -> 安全收口 | 适合把完整文章压缩成短视频 |

## 输出格式

按 `../_shared/intermediate-format.md` 中 `voice-script.md` 的结构，创建可交给审稿和人工发布确认的 Markdown 口播脚本文档。不要在聊天中输出代码块；聊天里只展示文档链接、口播策略摘要和需要用户确认的问题。

默认输出目录根据输入类型决定。文件名使用用户最终选择或确认的标题，不要使用英文前缀或 slug。用户指定保存路径时优先使用；指定目录则保存为 `<用户指定目录>/<用户选择的标题>.md`。

### 开头钩子备选

输出 3 条，每条不超过 35 字，并说明适合原因。

### 口播逐字稿

按用户指定时长输出。若用户没有指定，输出 90 秒版本。正文只写可直接录制的逐字稿，不加小标题和项目符号；节奏标注至少 3 处。

### 分镜建议

| 镜头 | 时长 | 画面内容 | 字幕重点 | 音乐/音效 | 对应口播 |
| ---: | --- | --- | --- | --- | --- |

分镜只做轻量建议，避免复杂剪辑自动化、自动视频生成或外部工具流程。

### 封面与发布素材

必须一起输出以下 4 类发布素材，供视频号、小红书或人工发布确认使用：

1. 封面提示词：输出 2 条，分别适合“真人口播封面”和“图文感封面”；包含画面主体、构图、氛围、主视觉文字位置和安全边界，不写夸张医美效果对比。
2. 标题：输出 5 个备选，每条不超过 20 字；要能直接作为视频标题或小红书标题，避免绝对化、制造焦虑和功效承诺。
3. 标签：输出 8-12 个，全部带 `#`，优先覆盖主题、人群、场景、账号定位和平台常用搜索词；不要用过度转化标签。
4. 评论区首条引导评论：输出 2 条备选，每条不超过 50 字；引导用户分享经历、提问面诊前判断点或补充自己的情况，但不做在线诊断、不引导价格和预约。

#### 封面标题

输出 5 个备选，分为：

- 避坑型
- 判断型
- 反常识型
- 收藏型
- 温和共鸣型

### 发布前风险表达

列出稿件中可能需要交给内容审稿（`adversarial-content-review`）复核的句子或表达方向。

## 最小测试

- 输入“根据这个大纲生成短视频口播稿”，应触发本 Skill，并输出 90 秒逐字稿、分镜建议、封面提示词、标题、带 `#` 标签、评论区首条引导评论和风险表达。
- 输入“/口播”，应优先触发本 Skill；如果用户给的是完整文章，也在本 Skill 内按文章改口播模式处理。
- 输入“把这篇文章改成 60 秒口播稿”，应输出约 180 字逐字稿，并保留原文核心观点。
- 输入“顺便给我封面和发布素材”，应在本 Skill 内补齐封面提示词、标题、标签和评论区首条引导评论，不转交其他 Skill。
- 涉及项目效果、恢复期或适应人群时，应保留面诊和个体差异提醒。

## 禁用倾向

- 不使用“保证、永久、立刻见效、无风险、最有效、必做、逆袭、换脸”等绝对或夸大表达。
- 不用羞辱外貌、制造恐慌或暗示不做项目就会失败的表达。
- 不把医生面诊、医学诊断和治疗建议简化成通用结论。
