# consultation-material-extractor

用于把 Emma 与客户之间的面诊转写整理成可长期复用的素材表。它是原始对话和后续 `digital-avatar`、`topic-generator` 之间的素材提炼层。

## 使用范围

使用这个 Skill 处理：

- 用户上传面诊录音转文字、分说话人转写、咨询对话或面诊素材
- 用户要求从面诊里提炼选题素材、客户问题、客户误区或背后担忧
- 用户要求沉淀 Emma 的追问、解释、边界表达和判断习惯
- 用户要求整理信任建立过程或临床判断逻辑

不要用这个 Skill：

- 不总结面诊经过
- 不复述聊天内容
- 不写文章、口播稿或发布文案
- 不记录具体项目名称
- 不生成完整数字分身；只输出可供 `digital-avatar` 参考的表达样本

## 核心规则

- 只提炼有原文依据的素材；没有体现的信息写“未体现”，不要编造。
- 客户原话只保留短句，去除姓名、联系方式、具体身份、地址、价格等隐私或可识别信息。
- 不记录项目名称。遇到项目名时，改写成更上位的非项目表达，例如“某类治疗诉求”“某类改善方式”。
- 不替客户下诊断结论，只提炼 Emma 的判断顺序、排除逻辑、解释方式和长期管理思维。
- 语音转写里的说话人标签不一定可靠。先根据内容判断谁更像客户、谁更像 Emma；无法判断时标为“说话人待确认”。

## 默认写入位置

除非用户指定目录，默认写入当前工作区：

`content-production/面诊素材提炼/`

固定维护 4 类素材表：

| 素材库 | 文件名 |
| --- | --- |
| 选题素材库 | `01-选题素材库-001.md` |
| Emma 表达样本库 | `02-Emma表达样本库-001.md` |
| 信任建立案例库 | `03-信任建立案例库-001.md` |
| 临床判断案例库 | `04-临床判断案例库-001.md` |

## 持续写入规则

- 每个素材库单独累计表格。
- 每张表最多 50 条素材，不含表头和分隔行。
- 下一次上传新面诊转写时，继续追加到当前编号最大的表。
- 当前表已满 50 条时，新建下一张，例如 `001` 满了就新建 `002`。
- 只追加，不覆盖、不删除、不重写已有素材。
- 每条素材必须有“来源”，优先写来源文件名；没有文件名时写日期或“本次对话”。

## 执行流程

1. 读取面诊转写，确认来源文件名或来源日期。
2. 判断说话人归属：客户通常表达困扰、担忧、误区；Emma 通常追问、解释、排除、给边界和判断。
3. 把对话拆成素材单元。一个客户问题、一次信任转折或一个判断逻辑可以形成一条素材。
4. 分别写入 4 类素材表。没有对应内容的库可以不追加空行。
5. 写入前检查当前表格是否已满 50 条；满了就新建下一编号。
6. 完成后只回复：写入了哪些文件、各新增多少条、是否有待确认的说话人或信息缺口。
